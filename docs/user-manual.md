# 使用手册（家长必读）

## 快速上手

1. 用 Chrome 或 Edge 浏览器打开 `index.html`（或访问部署地址）
2. 首次进入会引导选择**宝贝的年龄**（3-4 / 5-6 / 7-8 / 9-12 岁）
3. 在首页点选任意乐园模块开始学习，完成游戏可获得 ⭐ 星星

## 界面说明

### 顶栏（从左到右）
- **🎈 学习乐园**：点击随时回到首页
- **年龄标签**（如"7-8岁"）：点击可随时切换难度，内容会跟着变化
- **⭐ 星星数**：宝贝累计获得的星星总数
- **🔊 声音开关**：关闭后所有音效、伴奏、朗读静音
- **🌙 护眼模式**：切换暖色护眼主题（米黄底、柔和对比度），设置会记住

### 首页
- 六大模块卡片：显示当前年龄段的内容数量
- **荣誉墙**：星星达到 10/30/60/100/200 解锁 🥉🥈🥇🏆👑 勋章

### 底部导航（手机/平板）
手机上显示底部导航栏：首页 / 古诗 / 识字 / 数学 / 更多；电脑上用顶栏返回首页即可。

## 各模块玩法

### 📖 古诗背诵
1. 选择一首诗进入详情页
2. 点 **🔊 听朗读**（电脑朗读全诗）；低龄古诗带拼音注音
3. 点 **💬** 查看白话文解释
4. 点 **填字闯关 🚀**：5 道选字补全诗句的题目，全对得 3 颗星

### 🔤 识字乐园
- **卡片学习**：大字卡显示汉字和配图，点卡片翻面看拼音、词语、例句；点 🔊 听发音；‹ › 翻页
- **找字游戏**：听发音/看拼音，在 9 宫格中找出正确的字，共 8 关

### 🎵 儿歌欢唱
- 带 **♪ 有伴奏** 标记的儿歌：点 ▶ 播放电子琴伴奏，**当前唱到的歌词行会高亮**，跟着唱即可；唱完奖励星星
- 其他儿歌：点 🔊 跟着朗读学唱

### 📚 课文阅读
1. 选择一篇短文，可点 **🔊 听朗读** 或自己阅读
2. 点 **开始答题** 完成阅读理解选择题

### ✂️ 手工课堂
1. 查看材料清单，提前准备
2. 跟着步骤做，**每完成一步点一下该步骤**打卡
3. 全部完成会获得奖励；点"重新开始"可重置打卡

⚠️ **安全提示**：涉及剪刀、扎孔等步骤的手工（纸杯传声筒、风筝等），请家长陪同操作。

### 🔢 数学闯关
10 道题一轮：小年龄是数一数、比大小、5 以内加法；大年龄有乘除法和三位数运算。答完自动结算星星。

## 护眼功能

- **护眼模式**：点右上角 🌙，整个界面切换为暖色调，减少蓝光刺激
- **休息提醒**：连续使用 20 分钟会弹出"小眼睛累啦"全屏提醒，倒计时 20 秒，引导宝贝望远休息。可在年龄选择弹窗底部开关此功能
- 建议单次学习不超过 20-30 分钟，配合提醒让眼睛休息

## 常见问题

**Q：朗读没有声音？**
Chrome/Edge 首次需点击页面后才能发声（浏览器自动播放策略）；检查右上角声音是否已开启。

**Q：伴奏没有声音？**
同上，先点一下页面任意位置再播放；确认声音开关已打开。

**Q：进度会丢失吗？**
不会。年龄、星星、完成记录都保存在本机浏览器中（localStorage）。清除浏览器数据才会重置。

**Q：想换难度？**
点顶栏年龄标签随时切换。高年龄包含低年龄全部内容，方便复习。

**Q：如何全屏使用？**
电脑按 F11，手机浏览器菜单里选择"添加到主屏幕"可获得类 App 体验。
