# 使用手册（家长必读）

## 快速上手

1. 用 Chrome 或 Edge 浏览器打开 `index.html`（或访问部署地址）
2. 首次进入会引导**给宝贝建档**：填写昵称、选一个可爱头像，还可填生日（选了生日会自动按年龄定难度，非常省心）
3. 在首页点选任意乐园模块开始学习，完成游戏可获得 ⭐ 星星
4. 攒星星可以在**动画小剧场**兑换动画时间，学习娱乐两不误

## 界面说明

### 顶栏（从左到右）
- **🎈 学习乐园**：点击随时回到首页
- **年龄标签**（如"7-8岁"）：点击可随时切换难度，内容会跟着变化
- **⭐ 星星数**：宝贝累计获得的星星总数
- **🔊 声音开关**：关闭后所有音效、伴奏、朗读静音
- **🌙 护眼模式**：切换暖色护眼主题（米黄底、柔和对比度），设置会记住

### 家长入口
点击底部「更多」页面底部即可进入家长中心（4 位密码保护）。

## 新功能：古诗阶梯解锁 + 动画奖励 + 家长中心

### 📖 古诗背诵（阶梯解锁）
1. 每个年龄段有**核心古诗**和**扩展古诗**两部分
2. 先完成核心古诗闯关（每首 5 道填字题）
3. 该年龄段核心诗**全部闯关完成后**，自动解锁 3 首新的扩展古诗，循序渐进，越学越多！

### 🎬 动画小剧场（星星兑换 + 内置播放器）
- 在首页点**动画小剧场**卡片
- 页面会显示"当前 X / 所需星星数"进度条
- 星星够了点"兑换"按钮：扣除星星 → 增加动画时间（默认 20 颗星星换 30 分钟，家长可调）
- 兑换成功后可以：
  - 看**内置动画小剧场**（火箭太空、海底吐泡泡、蝴蝶花园，纯 CSS 动画，无需联网）
  - 播放**我添加的动画**：点"▶ 播放"在应用内直接播放（支持 mp4 直链、YouTube、Bilibili 链接）
- 播放器会显示**剩余时间倒计时**，剩余 5 分钟内会变红闪烁
- **时间到会自动停止播放**并弹出提示，必须再去学习赚星星才能继续看

#### 📚 推荐动画库 & 全网搜索
- 在动画小剧场页面点"去推荐动画库"
- **一键添加**：精选 20 部热门动画（汪汪队、小猪佩奇、宝宝巴士等），点一下就加到自己的库
- **全网搜索**：输入动画名称 → 点"去B站/YouTube搜索" → 在搜索页找到喜欢的视频 → 复制链接粘贴回来 → 点"添加"
- 首次使用会自动预填充 3 部经典动画

#### ⏱ 时间限制说明
- 动画在应用**内置播放器**中播放，因此可以精确计时
- 即使切到后台，倒计时也会继续；时间到了视频会被强制停止
- 这样既能看动画放松，又能控制时间、保护眼睛

### 👨‍👩‍👧 家长中心（从「更多」页底部进入）
首次进入会设置一个 4 位家长密码（防小朋友自己改设置），之后每次进入需输密码。家长中心包含：

- **宝贝档案**：修改昵称、头像、生日；填了生日会自动按年龄定学习难度
- **奖励与护眼**：设置"多少颗星星换多少分钟动画"、开关护眼休息提醒、清零动画时间、重置学习进度
- **动画库管理**：添加/删除自定义动画链接（标题 + 视频网址 + 图标），内置 3 个小剧场无需管理
- **小爱音箱联动**：配置桥接地址、选择音箱、开关得星表扬/升级播报/定时提醒（详见下方专章）
- **学习报告**：星星总数、古诗/课文/儿歌/手工完成数、认识了多少字、剩余动画时间，一目了然

### 🔊 小爱音箱联动

小爱音箱联动功能让宝贝的学习成果通过语音播报出来，更有成就感！需要在电脑上运行一个桥接服务（`tools/xiaoai_bridge.py`），手机 APP 与电脑需在同一个 WiFi 下。

#### 第一步：启动桥接服务

在电脑上打开命令行（PowerShell / CMD），进入项目目录，运行：

```bash
# 演示模式（无需小米账号，先体验功能）
python tools/xiaoai_bridge.py --mock

# 真实模式（需要小米账号，音箱会真响）
python tools/xiaoai_bridge.py --user 你的小米账号 --password 密码
```

启动后窗口会显示一个局域网地址，如 `http://192.168.1.5:8899`，记下这个地址。

#### 第二步：在家长中心配置

1. 进入家长中心 → 小爱音箱
2. 把桥接地址填入"桥接地址"输入框
3. 点"刷新设备"按钮，稍等片刻，音箱列表会自动拉取
4. 从下拉框选择要使用的音箱
5. 打开总开关，按需开启以下功能：
   - **⭐ 得星表扬**：宝贝每次得到星星，小爱音箱会语音表扬（如"小明得到一颗小星星，真棒！"）
   - **🎉 宠物升级**：学习小伙伴升级时，小爱音箱播报庆祝消息
   - **⏰ 定时学习提醒**：在设定的时间点（如 19:30、20:30），小爱音箱提醒宝贝来学习
6. 可设置最多两个提醒时间

#### 第三步：体验

配置完成后，让宝贝去学习得星星，小爱音箱会自动播报表扬！

> 💡 **提示**：首次登录小米账号会在本机生成 `~/.mi.token` 缓存，之后无需重复输入密码。账号密码只留在本机，不会发给其他服务器。

### 🐾 学习小伙伴互动升级

学习小伙伴现在支持 **12 类互动场景**，聊天更有趣：

#### 🎮 多轮游戏类
- **猜谜语**：出谜面，宝贝猜答案，有提示和揭晓功能
- **猜数字**：心里想一个 1-100 的数字，宝贝猜，大了/小了给反馈
- **石头剪刀布**：带比分追踪，看谁赢得多
- **反义词对对碰**：说一个词，宝贝说反义词，多轮计分
- **看 emoji 猜成语**：用 emoji 表情组合提示，宝贝猜成语
- **脑筋急转弯**：趣味急转弯，答对有惊喜

#### 🎭 趣味内容类
- **讲笑话**：随机讲一个适合宝贝年龄的笑话
- **绕口令**：挑战绕口令，语速会放慢
- **动物叫声**：听声音猜动物，或学说动物叫声

#### 🕐 生活助手类
- **今天几号**：告诉宝贝今天的日期和星期
- **现在几点**：告诉宝贝当前时间
- **今天天气**：根据季节和天气给提示
- **习惯提醒**：晚上 9 点后会自动提醒"该睡觉觉了哦"

#### 📚 学习增强类
- **讲个有趣的小知识**：科普小知识
- **陪我背古诗**：跟读古诗
- **给我出道数学题**：按年龄出题
- **唱首儿歌吧**：唱儿歌

> 💡 聊天面板底部有快捷按钮，低龄和高龄各 8 个，一键发起对应互动。

### 今日推荐与个性化
首页会根据宝贝当前年龄段和完成进度，推荐 3 个还没学过的内容，头像和昵称也会显示在首页问候里。高年龄段自动包含低年龄段内容，方便复习。

### 首页
- 六大模块卡片 + 动画小剧场卡片：显示当前年龄段的内容数量
- **荣誉墙**：星星达到 10/30/60/100/200 解锁 🥉🥈🥇🏆👑 勋章

### 底部导航（手机/平板）
手机上显示底部导航栏：首页 / 古诗 / 数学 / 更多；电脑上用顶栏返回首页即可。
「更多」里包含：识字、儿歌、课文、手工、动画小剧场，以及家长中心入口。

## 各模块玩法

### 📖 古诗背诵
1. 选择一首诗进入详情页
2. 点 **🔊 听朗读**（电脑朗读全诗）；低龄古诗带拼音注音
3. 点 **💬** 查看白话文解释
4. 点 **填字闯关 🚀**：5 道选字补全诗句的题目，全对得 3 颗星

### 🔤 识字乐园
- **卡片学习**：大字卡显示汉字和配图，点卡片翻面看拼音、词语、例句；点 🔊 听发音；‹ › 翻页
- **找字游戏**：听发音/看拼音，在 9 宫格中找出正确的字，共 8 关

### 🎵 儿歌欢唱
- 带 **♪ 有伴奏** 标记的儿歌：点 ▶ 播放电子琴伴奏，**当前唱到的歌词行会高亮**，跟着唱即可；唱完奖励星星
- 其他儿歌：点 🔊 跟着朗读学唱

### 📚 课文阅读
1. 选择一篇短文，可点 **🔊 听朗读** 或自己阅读
2. 点 **开始答题** 完成阅读理解选择题

### ✂️ 手工课堂
1. 查看材料清单，提前准备
2. 跟着步骤做，**每完成一步点一下该步骤**打卡
3. 全部完成会获得奖励；点"重新开始"可重置打卡

⚠️ **安全提示**：涉及剪刀、扎孔等步骤的手工（纸杯传声筒、风筝等），请家长陪同操作。

### 🔢 数学闯关
10 道题一轮：小年龄是数一数、比大小、5 以内加法；大年龄有乘除法和三位数运算。答完自动结算星星。

## 护眼功能

- **护眼模式**：点右上角 🌙，整个界面切换为暖色调，减少蓝光刺激
- **休息提醒**：连续使用 20 分钟会弹出"小眼睛累啦"全屏提醒，倒计时 20 秒，引导宝贝望远休息。可在家长中心开关此功能
- 建议单次学习不超过 20-30 分钟，配合提醒让眼睛休息

## 常见问题

**Q：朗读没有声音？**
Chrome/Edge 首次需点击页面后才能发声（浏览器自动播放策略）；检查右上角声音是否已开启。

**Q：伴奏没有声音？**
同上，先点一下页面任意位置再播放；确认声音开关已打开。

**Q：进度会丢失吗？**
不会。年龄、星星、完成记录都保存在本机浏览器中（localStorage）。清除浏览器数据才会重置。

**Q：想换难度？**
点顶栏年龄标签随时切换。高年龄包含低年龄全部内容，方便复习。

**Q：如何全屏使用？**
电脑按 F11，手机浏览器菜单里选择"添加到主屏幕"可获得类 App 体验。
