# 项目历程

## 2026-09-14 v1.0.0 首版发布

**需求**：面向 3-12 岁儿童的益智学习应用，含古诗、识字、儿歌、课文、手工等多个模块，要求护眼模式、多屏幕适配、按年龄分层。

**实现**：
- 纯静态零依赖架构（原生 HTML/CSS/JS + hash 路由），双击即用、可静态托管
- 六大模块：古诗填字闯关、识字翻卡/找字、儿歌伴奏跟唱、课文阅读理解、手工步骤打卡、数学程序化出题
- 四级年龄分层（3-4/5-6/7-8/9-12），高年龄包含低年龄内容
- 护眼模式（暖色主题 + 20 分钟休息提醒倒计时）
- 星星奖励 + 五级荣誉勋章，进度 localStorage 持久化
- Web Audio 音效/电子琴伴奏 + SpeechSynthesis 中文朗读

**浏览器实测修复的 bug**：
1. main.js 使用未定义的 `$` → 欢迎弹窗按钮绑定失败
2. 儿歌播完后星星双倍发放（song.js 手动 addStars 与 showResult 内部加星重复）
3. mathgen.js 引用未定义的 `shuffle` → 数学模块渲染失败
4. `Object.assign` 展开 getter 被求值为静态值 → `CS.muted` 永不更新、静音开关失效（改为 `getMuted()` 函数）

**验证**：Chrome DevTools MCP 实测六大模块完整通关流程、年龄切换、护眼/声音开关持久化、手机/桌面响应式、休息提醒触发与关闭，控制台零报错。

## 2026-09-14 v1.1.0 古诗扩库 + 宝贝档案 + 动画奖励 + 家长中心

**新增功能**：
- **古诗阶梯解锁**：`poems.js` 从 20 首扩至 32 首，每年龄段新增 3 首 `tier:'extra'` 扩展诗；同年龄段核心诗全部闯关后自动解锁扩展诗，列表页显示锁定占位 + 进度提示
- **宝贝档案**：首次进入引导建档（昵称 + 12 款头像 + 可选生日）；填生日自动按年龄（<5→a1 / <7→a2 / <9→a3 / 其他→a4）定难度；首页个性化问候与头像
- **动画小剧场**：星星兑换动画时长（`CS.reward.exchange`，默认 20 星→30 分钟）；内置 3 个纯 CSS 动画场景（太空火箭 / 海底吐泡泡 / 蝴蝶花园）；观看倒计时，页面隐藏不计时，剩余 <5 分钟横幅变红闪烁，归零自动锁定
- **家长控制端**（⚙️ 入口）：4 位 PIN 码保护；含宝贝档案编辑、奖励规则与护眼开关、自定义动画链接管理（增删 + https 校验）、学习报告、动画时间清零、学习进度重置
- **首页增强**：今日推荐（基于年龄与完成度随机推 3 个未完成项）、动画入口卡片、问候语联动档案

**实测**：建档→选头像→古诗核心全通关解锁扩展诗→攒星兑换→打开小剧场与自定义链接→家长中心 PIN/档案/报告/添加动画全流程通过；修复建档后首页问候未刷新的 render 调用、表单 label 缺少 `for` 关联的无障碍警告。

## 2026-09-19 v1.4.0 童话城堡 + 宠物对话修复 + 投喂升级系统

**新增模块 🏰 童话城堡**：
- 16 篇**原创**童话故事（4 个年龄段各 4 篇），全新创作避免版权
- 听朗读 → 自主阅读 → 阅读理解答题（2-3 题）；全对 3⭐ / 70% 以上 2⭐ / 其他 1⭐
- **道理揭晓机制**：答题前故事道理 🔒 锁定，答完题后揭晓 moral 道理框

**🐾 学习小伙伴（宠物）全面升级**：
- **离线对话大脑**（`ai.js` 重写）：无需配置 AI 即可聊天，意图识别覆盖算术问答（多轮追问 pendingMath）、讲童话、背古诗、唱儿歌、按年龄出数学题、问候/告别/感谢、自我介绍、宠物等级查询、情感陪伴
- **语音麦克风输入**：Web Speech Recognition，聊天面板底部 🎤 按钮切换监听（`mic-on` 脉冲动画）
- **投喂升级系统**（`pet.js`）：消耗星星换宠物经验
  - 3 种食物：🍎 苹果 3⭐=15exp / 🍪 饼干 5⭐=30exp / 🎂 蛋糕 10⭐=60exp
  - 10 级成长线：蛋宝宝 → 破壳啦 → 小不点 → 小可爱 → 好伙伴 → 小学学霸 → 大朋友 → 小超人 → 小巨人 → 传说伙伴
  - 学习得星自动涨经验（`addStars()` 联动 `gainExp()`）；升级触发撒花 + 语音播报 + `cs:pet-levelup` 事件
- **点击热区修复**：`.mascot` 容器 `pointer-events: none`（防止漫步宠物遮挡页面按钮），内部 `.pet-hit` 圆形热区接收点击，解决宠物挡住"开始答题"等按钮的问题

**语音管线增强**：`export-voice-tasks.js` 与 `gen-voice.py` 支持 story 分类，便于后续预生成童话朗读音频。

**浏览器实测**：故事列表→详情→答题（滚动点击）→道理揭晓→得星；宠物面板→投喂苹果/饼干（扣星+经验正确）→喂蛋糕被正确拒绝（星不够）→升级播报与徽章刷新；离线对话"你好"→友好回复、快捷按钮"陪我背古诗"→《咏鹅》跟读；麦克风按钮 `mic-on` 监听状态切换正常。

## 2026-09-21 v1.5.0 趣味内容库 + 小爱音箱联动 + 闭包修复

**新增模块 🔊 小爱音箱联动**：
- **桥接服务**（`tools/xiaoai_bridge.py`）：Python HTTP 服务，底层用 `miservice_fork` 登录小米账号调用小爱 TTS；浏览器直连小米云会被 CORS 拦截，故通过本机桥接转发
  - 接口：`GET /status`（服务状态）、`GET /devices`（音箱列表）、`GET /say?text=…&device=…`（播报）
  - 演示模式 `--mock`：无需账号，播报内容只打印到窗口，用于先体验页面功能
  - 默认端口 8899，启动后打印局域网地址（如 `http://192.168.1.5:8899`）
- **前端模块**（`js/xiaoai.js`）：配置/播报/提醒计时器
  - 配置项：总开关 `on`、桥接地址 `url`、指定音箱 `device`、得星表扬 `praise`、升级播报 `levelup`、定时提醒 `remind` + `remindTimes`
  - 得星表扬：短时间多次得星合并播一条（900ms 防刷屏），语音含宝贝昵称
  - 宠物升级：监听 `cs:pet-levelup` 事件自动播报庆祝
  - 定时提醒：每 20 秒检查 HH:mm，到点且当天未播过才播（`fired` 字典去重）
  - 播报失败静默不弹窗，避免打扰孩子
- **家长中心配置卡**：桥接地址输入、音箱下拉选择（自动拉取设备列表）、三个独立开关（得星表扬/升级播报/定时提醒）、两个提醒时间输入

**🐾 学习小伙伴互动升级（12 类新场景）**：
- **趣味内容库**（`js/data/fun.js`）：谜语 24 则、笑话 12 则、绕口令 12 则、脑筋急转弯 12 则、反义词 24 组、看 emoji 猜成语 15 则、动物叫声 24 种，按年龄分层
- **统一游戏状态机**（`js/ai.js` 扩展）：多轮问答类（猜谜语/猜数字/反义词/看emoji猜成语/脑筋急转弯）支持"答案校验→提示→揭晓"流程；猜数字给"大了/小了"反馈；石头剪刀布带比分追踪
- **生活助手**：日期/时间/天气查询（真实系统时间）；21:00 后自动提醒"该睡觉觉了"
- **快捷按钮扩展**：低龄 8 个（讲个有趣的小知识/陪我背古诗/给我出道数学题/唱首儿歌吧/猜谜语/讲个笑话/石头剪刀布/今天几号），高龄 8 个（讲个童话故事/背首古诗/给我出道数学题/唱首儿歌/猜谜语/讲个笑话/石头剪刀布/今天几号）

**🐛 闭包过期变量修复**：
- **问题**：`tabXiaoai()` 和 `tabAI()` 的 `readForm()` 在渲染时捕获了 `cfg` 对象引用，但 `CS.xiaoai.update()` / `CS.ai.save()` 每次更新都替换整个对象（`Object.assign({}, cfg, patch)`），导致闭包持有的旧引用读到过期状态——外部修改配置后，切换按钮仍按旧值切换
- **修复**：`readForm()` 内改为每次实时读取 `CS.xiaoai.cfg` / `state.ai`；toggle 处理器改用 `readForm()` 返回的 `cur` 取反
- **浏览器缓存**：`parent.js` 加 `?v=1.5.0` 查询字符串强制加载修复版

**浏览器实测**：外部修改 `cfg.remind=false` → 点击开关 → `cfg.remind=true` ✓；外部 `praise=false` → 点击 → `true` ✓；外部 `levelup=false` → 点击 → `true` ✓；外部 `on=false` → 点击 → `true` ✓；AI 总开关外部 `on=true` → 点击 → `false` ✓；全流程控制台零报错。
