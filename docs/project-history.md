# 项目历程

## 2026-09-14 v1.0.0 首版发布

**需求**：面向 3-12 岁儿童的益智学习应用，含古诗、识字、儿歌、课文、手工等多个模块，要求护眼模式、多屏幕适配、按年龄分层。

**实现**：
- 纯静态零依赖架构（原生 HTML/CSS/JS + hash 路由），双击即用、可静态托管
- 六大模块：古诗填字闯关、识字翻卡/找字、儿歌伴奏跟唱、课文阅读理解、手工步骤打卡、数学程序化出题
- 四级年龄分层（3-4/5-6/7-8/9-12），高年龄包含低年龄内容
- 护眼模式（暖色主题 + 20 分钟休息提醒倒计时）
- 星星奖励 + 五级荣誉勋章，进度 localStorage 持久化
- Web Audio 音效/电子琴伴奏 + SpeechSynthesis 中文朗读

**浏览器实测修复的 bug**：
1. main.js 使用未定义的 `$` → 欢迎弹窗按钮绑定失败
2. 儿歌播完后星星双倍发放（song.js 手动 addStars 与 showResult 内部加星重复）
3. mathgen.js 引用未定义的 `shuffle` → 数学模块渲染失败
4. `Object.assign` 展开 getter 被求值为静态值 → `CS.muted` 永不更新、静音开关失效（改为 `getMuted()` 函数）

**验证**：Chrome DevTools MCP 实测六大模块完整通关流程、年龄切换、护眼/声音开关持久化、手机/桌面响应式、休息提醒触发与关闭，控制台零报错。
