# 项目历程

## 2026-09-14 v1.0.0 首版发布

**需求**：面向 3-12 岁儿童的益智学习应用，含古诗、识字、儿歌、课文、手工等多个模块，要求护眼模式、多屏幕适配、按年龄分层。

**实现**：
- 纯静态零依赖架构（原生 HTML/CSS/JS + hash 路由），双击即用、可静态托管
- 六大模块：古诗填字闯关、识字翻卡/找字、儿歌伴奏跟唱、课文阅读理解、手工步骤打卡、数学程序化出题
- 四级年龄分层（3-4/5-6/7-8/9-12），高年龄包含低年龄内容
- 护眼模式（暖色主题 + 20 分钟休息提醒倒计时）
- 星星奖励 + 五级荣誉勋章，进度 localStorage 持久化
- Web Audio 音效/电子琴伴奏 + SpeechSynthesis 中文朗读

**浏览器实测修复的 bug**：
1. main.js 使用未定义的 `$` → 欢迎弹窗按钮绑定失败
2. 儿歌播完后星星双倍发放（song.js 手动 addStars 与 showResult 内部加星重复）
3. mathgen.js 引用未定义的 `shuffle` → 数学模块渲染失败
4. `Object.assign` 展开 getter 被求值为静态值 → `CS.muted` 永不更新、静音开关失效（改为 `getMuted()` 函数）

**验证**：Chrome DevTools MCP 实测六大模块完整通关流程、年龄切换、护眼/声音开关持久化、手机/桌面响应式、休息提醒触发与关闭，控制台零报错。

## 2026-09-14 v1.1.0 古诗扩库 + 宝贝档案 + 动画奖励 + 家长中心

**新增功能**：
- **古诗阶梯解锁**：`poems.js` 从 20 首扩至 32 首，每年龄段新增 3 首 `tier:'extra'` 扩展诗；同年龄段核心诗全部闯关后自动解锁扩展诗，列表页显示锁定占位 + 进度提示
- **宝贝档案**：首次进入引导建档（昵称 + 12 款头像 + 可选生日）；填生日自动按年龄（<5→a1 / <7→a2 / <9→a3 / 其他→a4）定难度；首页个性化问候与头像
- **动画小剧场**：星星兑换动画时长（`CS.reward.exchange`，默认 20 星→30 分钟）；内置 3 个纯 CSS 动画场景（太空火箭 / 海底吐泡泡 / 蝴蝶花园）；观看倒计时，页面隐藏不计时，剩余 <5 分钟横幅变红闪烁，归零自动锁定
- **家长控制端**（⚙️ 入口）：4 位 PIN 码保护；含宝贝档案编辑、奖励规则与护眼开关、自定义动画链接管理（增删 + https 校验）、学习报告、动画时间清零、学习进度重置
- **首页增强**：今日推荐（基于年龄与完成度随机推 3 个未完成项）、动画入口卡片、问候语联动档案

**实测**：建档→选头像→古诗核心全通关解锁扩展诗→攒星兑换→打开小剧场与自定义链接→家长中心 PIN/档案/报告/添加动画全流程通过；修复建档后首页问候未刷新的 render 调用、表单 label 缺少 `for` 关联的无障碍警告。

## 2026-09-14 v1.3.0 导航精简 + 内置视频播放器 + 动画库增强

**导航精简**：底栏 5→4 项（首页/古诗/数学/更多）；顶栏去掉家长中心按钮（改从"更多"进入）；浮动装饰 6→4 个。

**动画库**：首次预填充 3 部默认动画；20 部热门推荐一键添加；全网搜索（跳转 B站/YouTube）+ 粘贴链接手动录入。
