## 🏗️ 项目架构原理

### 整体架构

```
┌─────────────────────────────────────────────────────────┐
│                    单页应用（SPA）                        │
│              hash 路由 + 零依赖经典脚本                    │
├─────────────────────────────────────────────────────────┤
│  index.html（入口）                                      │
│    ├─ css/style.css      ← 全部样式（护眼主题/响应式/动画）│
│    ├─ js/data/*.js       ← 纯内容数据（按年龄标签分层）    │
│    ├─ js/core.js         ← 工具/存储/状态/路由            │
│    ├─ js/audio.js        ← 音频引擎（Web Audio + 语音合成）│
│    ├─ js/ui.js           ← 共享 UI 组件                   │
│    ├─ js/xiaoai.js       ← 小爱音箱联动（配置/播报/提醒） │
│    ├─ js/ai.js           ← 离线对话大脑 + 12 类互动游戏    │
│    ├─ js/pet.js          ← 宠物成长系统                   │
│    ├─ js/animal.js       ← 动物 SVG 渲染                  │
│    ├─ js/modules/*.js    ← 模块页面逻辑（home/poem/...）  │
│    └─ js/main.js         ← 启动引导                       │
├─────────────────────────────────────────────────────────┤
│  tools/xiaoai_bridge.py  ← 小爱音箱本地桥接服务（Python） │
└─────────────────────────────────────────────────────────┘
```

### 核心机制

#### 路由系统（hash-based）
- 采用 `#/模块名?id=参数` 格式，如 `#/poem?id=p1`、`#/parent`
- `CS.register(name, renderFn)` 注册路由，`CS.navigate(name, params)` 跳转
- 每次切换路由统一 `CS.stopMelody()` + `CS.stopSpeak()`，防止声音残留
- 模块内部列表/详情由同一 renderFn 按 `params.id` 分发

#### 状态管理（localStorage）
- 所有状态存于 `localStorage`，前缀 `cs_`，刷新不丢失
- 核心状态：`age`（年龄组）、`stars`（星星数）、`sound`（声音开关）、`eyeCare`（护眼模式）、`done`（完成标记）、`profile`（宝贝档案）、`reward`（兑换规则）、`cartoonMins`（动画剩余时间）、`pin`（家长密码）
- 小爱音箱配置：`cs_xiaoai` 键，含 `on/url/device/praise/levelup/remind/remindTimes`

#### 音频引擎
- **音效**：Web Audio API 合成 tap/correct/wrong/star/finish 短音效
- **旋律**：简谱字符串驱动（`CS.parseMelody('1 1 5 5 6 6 5 -')`），支持高八度 `1+`、低八度 `5_`、延长 `-`
- **语音朗读**：SpeechSynthesis（zh-CN），古诗/字卡/课文/歌词均可发声
- **小爱音箱 TTS**：通过局域网 Python 桥接服务调用，浏览器直连小米云受 CORS 限制

#### 数据与逻辑分离
- `js/data/` 目录存放纯内容数据（古诗、字卡、儿歌、课文、手工、童话、数学出题器、趣味内容库）
- 所有条目带 `age: 'a1'|'a2'|'a3'|'a4'` 标签，渲染时按 `CS.agePool(state.age)` 过滤
- 新增内容只需加数据条目，无需修改逻辑代码

#### 小爱音箱联动架构
```
浏览器/APP  ──HTTP──→  xiaoai_bridge.py（本机 8899 端口）
   │                         │
   │  GET /say?text=…        │  miservice_fork 登录小米云
   │  GET /devices           │
   │  GET /status            ↓
   │                    小爱音箱 TTS 播报
```

## 🚀 使用安装教程

### 方式一：本地 HTTP 服务器（推荐）

> ⚠️ **重要**：本应用需要运行在本地 HTTP 服务器上（不能直接双击 `index.html`），否则动画播放器的 YouTube/Biframe 嵌入会被浏览器安全策略拦截。

#### 一键启动（推荐）

双击运行 `start-server.bat`，然后浏览器访问 **http://localhost:8080**

#### 或手动启动

```bash
# Python（推荐）
python -m http.server 8080

# Node.js
npx serve .

# VS Code：安装 Live Server 插件后右键 index.html → Open with Live Server
```

启动后访问 http://localhost:8080 即可。

### 方式二：静态托管

由于是纯静态应用，可托管到任意静态空间：
- **GitHub Pages**：推送仓库后开启 Pages 功能
- **Netlify / Vercel**：拖拽部署
- **任意 Web 服务器**：Nginx / Apache 等

### 小爱音箱联动配置（可选）

如需使用小爱音箱语音播报功能：

1. **安装依赖**（只需一次）：
   ```bash
   pip install miservice_fork
   ```

2. **启动桥接服务**：
   ```bash
   # 演示模式（无需账号，先体验功能）
   python tools/xiaoai_bridge.py --mock

   # 真实模式（需要小米账号）
   python tools/xiaoai_bridge.py --user 你的小米账号 --password 密码
   ```

3. **在家长中心配置**：
   - 进入家长中心 → 小爱音箱
   - 填入桥接地址（如 `http://192.168.1.5:8899`）
   - 点"刷新设备"选择音箱
   - 打开总开关，按需开启得星表扬/升级播报/定时提醒

> 💡 手机 APP 与桥接服务需在同一个 WiFi / 局域网内。

### v1.5.0（2026-09-21）趣味内容库 + 小爱音箱联动 + 闭包修复

**新增模块 🔊 小爱音箱联动**：
- **桥接服务**（`tools/xiaoai_bridge.py`）：Python HTTP 服务，底层用 `miservice_fork` 登录小米账号调用小爱 TTS；浏览器直连小米云会被 CORS 拦截，故通过本机桥接转发
  - 接口：`GET /status`（服务状态）、`GET /devices`（音箱列表）、`GET /say?text=…&device=…`（播报）
  - 演示模式 `--mock`：无需账号，播报内容只打印到窗口，用于先体验页面功能
  - 默认端口 8899，启动后打印局域网地址（如 `http://192.168.1.5:8899`）
- **前端模块**（`js/xiaoai.js`）：配置/播报/提醒计时器
  - 配置项：总开关 `on`、桥接地址 `url`、指定音箱 `device`、得星表扬 `praise`、升级播报 `levelup`、定时提醒 `remind` + `remindTimes`
  - 得星表扬：短时间多次得星合并播一条（900ms 防刷屏），语音含宝贝昵称
  - 宠物升级：监听 `cs:pet-levelup` 事件自动播报庆祝
  - 定时提醒：每 20 秒检查 HH:mm，到点且当天未播过才播（`fired` 字典去重）
  - 播报失败静默不弹窗，避免打扰孩子
- **家长中心配置卡**：桥接地址输入、音箱下拉选择（自动拉取设备列表）、三个独立开关（得星表扬/升级播报/定时提醒）、两个提醒时间输入

**🐾 学习小伙伴互动升级（12 类新场景）**：
- **趣味内容库**（`js/data/fun.js`）：谜语 24 则、笑话 12 则、绕口令 12 则、脑筋急转弯 12 则、反义词 24 组、看 emoji 猜成语 15 则、动物叫声 24 种，按年龄分层

**🐛 闭包过期变量修复**：
- **问题**：`tabXiaoai()` 和 `tabAI()` 的 `readForm()` 在渲染时捕获了 `cfg` 对象引用，但 `CS.xiaoai.update()` / `CS.ai.save()` 每次更新都替换整个对象（`Object.assign({}, cfg, patch)`），导致闭包持有的旧引用读到过期状态——外部修改配置后，切换按钮仍按旧值切换
- **修复**：`readForm()` 内改为每次实时读取 `CS.xiaoai.cfg` / `state.ai`；toggle 处理器改用 `readForm()` 返回的 `cur` 取反
- **浏览器缓存**：`parent.js` 加 `?v=1.5.0` 查询字符串强制加载修复版

**浏览器实测**：外部修改 `cfg.remind=false` → 点击开关 → `cfg.remind=true` ✓；外部 `praise=false` → 点击 → `true` ✓；外部 `levelup=false` → 点击 → `true` ✓；外部 `on=false` → 点击 → `true` ✓；AI 总开关外部 `on=true` → 点击 → `false` ✓；全流程控制台零报错。

### v1.0.0（2026-09-14）首版发布

**需求**：面向 3-12 岁儿童的益智学习应用，含古诗、识字、儿歌、课文、手工等多个模块，要求护眼模式、多屏幕适配、按年龄分层。

**实现**：
- 纯静态零依赖架构（原生 HTML/CSS/JS + hash 路由），双击即用、可静态托管
- 六大模块：古诗填字闯关、识字翻卡/找字、儿歌伴奏跟唱、课文阅读理解、手工步骤打卡、数学程序化出题

- Web Audio 音效/电子琴伴奏 + SpeechSynthesis 中文朗读

**浏览器实测修复的 bug**：
1. main.js 使用未定义的 `$` → 欢迎弹窗按钮绑定失败
2. 儿歌播完后星星双倍发放（song.js 手动 addStars 与 showResult 内部加星重复）

## 🛠️ 技术说明

- **零依赖**：原生 HTML/CSS/JS，无构建步骤，可托管到任意静态空间（GitHub Pages 等）
- **数据与逻辑分离**：`js/data/` 纯数据，新增内容只需加数据条目
- **本地存储**：年龄、星星、进度、护眼等设置存于 localStorage，刷新不丢失
- **语音朗读**：浏览器内置 SpeechSynthesis（zh-CN），古诗/字卡/课文/歌词均可发声
- **音乐伴奏**：Web Audio API 合成电子琴音色，简谱数据驱动
- **小爱音箱联动**：通过局域网 Python 桥接服务（`tools/xiaoai_bridge.py`）调用小爱 TTS，实现得星表扬/升级庆祝/定时提醒语音播报；浏览器直连小米云受 CORS 限制，必须经桥接转发
