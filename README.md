# 🎈 儿童益智学习乐园

适合 **3-12 岁**孩子的纯前端趣味学习应用：古诗、识字、儿歌、课文、手工、数学六大模块，按年龄分层展示内容，自带**护眼模式**与**用眼休息提醒**，适配手机 / 平板 / 电脑多种屏幕。

## ✨ 功能特性

| 模块 | 内容 | 玩法 |
|------|------|------|
| 📖 古诗背诵 | 32 首经典古诗（3-4 岁带拼音注音），每年龄段核心+扩展 | 听朗读、看白话解释、**填字闯关**赢星星；核心诗全通关自动**解锁扩展诗** |
| 🔤 识字乐园 | 74 张字卡：单字 → 词语 → 成语 | 翻卡学习（拼音+例句+发音）、**找字游戏** |
| 🎵 儿歌欢唱 | 9 首经典儿歌 | 3 首内置电子琴伴奏，**歌词逐行跟唱高亮**，其余支持朗读 |
| 📚 课文阅读 | 12 篇原创分级短文 | 听朗读、自主阅读、**阅读理解答题** |
| ✂️ 手工课堂 | 8 个手工教程 | 材料清单 + **步骤打卡**，全部完成领奖励 |
| 🔢 数学闯关 | 无限量程序化出题 | 数数、比大小、加减、乘除，按年龄自适应 |
| 🎬 动画小剧场 | 3 个内置动画 + 预填充 3 部 + 20 部推荐库 + 全网搜索 | **内置播放器**（mp4/YouTube/Bilibili）+ 星星兑换时长 + 倒计时强制停止 |
| 👨‍👩‍👧 家长中心 | PIN 码保护，「更多」页进入 | 管档案、定奖励规则、加动画链接（一键添加/全网搜索）、看报告 |

### 护眼设计
- **护眼模式**：右上角 🌙 一键切换暖色护眼主题（米黄底色、柔和对比度），设置自动保存
- **休息提醒**：每连续学习 20 分钟弹出"小眼睛累啦"提醒，倒计时 20 秒引导远眺休息
- **奖励系统**：星星累计解锁荣誉勋章（10/30/60/100/200 ⭐）；攒满星星可**兑换动画时间**（默认 20 星 = 30 分钟），家长可自定义规则
- **宝贝档案**：建档后首页个性化问候；填生日自动匹配年龄难度
- 底栏 4 项精简导航（首页/古诗/数学/更多），顶栏清爽无冗余

### 年龄分层
| 年龄 | 分层 | 内容特点 |
|------|------|----------|
| 3-4 岁 | 启蒙小小班 | 超短句课文、单字卡、拼音注音古诗、数数 |
| 5-6 岁 | 学前准备班 | 拼音古诗、词语卡、10 以内加减 |
| 7-8 岁 | 小学低年级 | 七言诗、理解题、表内乘法 |
| 9-12 岁 | 小学高年级 | 哲理诗、成语卡、乘除法、三位数运算 |

高年龄段自动包含低年龄段内容，方便复习。

## 🚀 运行方式

> ⚠️ **重要**：本应用需要运行在本地 HTTP 服务器上（不能直接双击 `index.html`），否则动画播放器的 YouTube/Biframe 嵌入会被浏览器安全策略拦截。

### 一键启动（推荐）

双击运行 `start-server.bat`，然后浏览器访问 **http://localhost:8080**

### 或手动启动

```bash
# Python（推荐）
python -m http.server 8080

# Node.js
npx serve .

# VS Code：安装 Live Server 插件后右键 index.html → Open with Live Server
```

启动后访问 http://localhost:8080 即可。

## 🛠️ 技术说明

- **零依赖**：原生 HTML/CSS/JS，无构建步骤，可托管到任意静态空间（GitHub Pages 等）
- **数据与逻辑分离**：`js/data/` 纯数据，新增内容只需加数据条目
- **本地存储**：年龄、星星、进度、护眼等设置存于 localStorage，刷新不丢失
- **语音朗读**：浏览器内置 SpeechSynthesis（zh-CN），古诗/字卡/课文/歌词均可发声
- **音乐伴奏**：Web Audio API 合成电子琴音色，简谱数据驱动

更多细节见 [docs/user-manual.md](docs/user-manual.md)（使用手册）与 [docs/development.md](docs/development.md)（开发文档）。
